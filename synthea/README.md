# synthea/

Synthea disease module and generated artifacts for the PAD/SSI study.

## modules/

| File | Description |
|------|-------------|
| `pad_ssi.json` | Synthea state-machine module defining PAD disease progression, surgical intervention (open revascularization), and SSI outcomes. Encodes OMOP-mapped concept codes (SNOMED, LOINC, RxNorm) for all clinical states. This is the primary source of truth for synthetic cohort generation. |
| `pad_ssi.diagram.html` | Auto-generated Mermaid state-diagram visualization of `pad_ssi.json`. Regenerated by `workflow/03_generate_synthea_module_artifacts.R` whenever the module changes. Open in any browser to review module logic visually. |

## Module design

The PAD/SSI module simulates:

1. PAD diagnosis with intermittent claudication, rest pain, or tissue loss presentation
2. Pre-operative workup (ABI measurement, BMI, smoking status)
3. Open revascularization procedure (aorto-bifemoral, fem-pop, fem-tibial, or aorto-iliac bypass)
4. Optional prolonged pre-operative antibiotic exposure (20% of patients)
5. Post-operative SSI outcome (probabilistic based on risk factor burden)

All SNOMED, LOINC, and RxNorm codes in `pad_ssi.json` have been verified against the
live OMOP vocabulary (`omop_vocab.concept`) to ensure standard concept mapping.

## Updating the module

After editing `pad_ssi.json`:
1. Run `workflow/03_generate_synthea_module_artifacts.R` to regenerate the diagram.
2. Re-run Steps 04–06 to regenerate synthetic data and validate ETL output.
3. Verify affected OMOP concepts via `SELECT * FROM omop_vocab.concept WHERE concept_code = '<code>'`.
